## Le principe

Un **FPGA** est une puce dont on peut reconfigurer les circuits. Au lieu d'écrire un programme exécuté instruction par instruction, on **décrit le circuit lui-même** : les opérations se font alors en parallèle, au rythme de l'horloge.

## Ce qui a été réalisé

- **La description du circuit** dans un langage de description matérielle.
- **La simulation** pour vérifier le comportement avant implantation.
- **L'implantation** sur la carte avec **Intel Quartus**, puis les tests sur le matériel.
